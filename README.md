# Generative-Agentic-AI-Project
This project presents a generative agentic AI prototype designed to address operational inefficiencies and fragmented coordination within a retail organization, SmartShoe, using StackAI. The system leverages multi-agent coordination to streamline workflows, improve data exchange, and support automated decision-making.
Here is the link to access the AI Chatbot https://www.stackai.com/chat/69151ac5bef1a6ee72a6aba6-41ptbJ3YNgVYWhJ4NR0toG

The csv files uploaded to this repo are the synthetic data dedicated for each of the agent as their knowledge base, the agents were also instructed to access online resources to form their responses regarding particular matters. If they cannot solve the problems, as it do not belong to their expertise, it will be passed on to the appropriate agents.
